three-candidate Perception, 20 Solver examples, problem-directed Reviewer
instruction, three Reviewer iterations with a reserved final report, Planner,
one possible Solver revision and final normalizer. Both retain original speech,

Reviewer for intent-boundaries and slot-contracts. No second answering model.

call authority and result/history custody are shared production implementations.

lexical E36b query. All invocation occurs on demand inside the native Reviewer
loop; there is no mandatory preprocessing tool call.

Planner decides routing, Solver answers. The original candidate contract remains,
so correct intents absent from Perception cannot be claimed recovered by this
cell. Report that residual ceiling; candidate recovery needs its own admitted
transition rather than a silent prompt exception.
