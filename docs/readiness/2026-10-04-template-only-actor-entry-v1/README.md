# Template-only actor entry preparation

Connect the shared learner and callback exchange to bounded aggregate-only actors. Both the TF batch experience update and proposals receive complete editable template systems with aggregate evidence. The batch updater previously received only metrics; this prospective path adds the missing template and priority context without sample material.

`prepare_template_actor_capsule` in the existing exchange module validates request/task commitments, an unconsumed semantic stage, zero-case profile, complete restricted policy views, excluded knowledge/source fields, absent sample identifiers and the exact instruction hash. It publishes create-only snapshots of two allowed files plus their manifest. It does not contact an actor, reserve a proposal, countersign READ or dispatch runtime. The root must separately admit the exact manifest. Unknown metering remains unknown; byte limits are not model token caps or OS-enforced filesystem isolation. Use fork-none actors and the declared allowed-file instructions.

The prepared protocol preserves N20/K4, fixed supply and distinct complete contexts, T0/fixed seed, independent TF/GEPA histories, whole-family evaluation and measured latency. It has no live input family or parent decision yet, and is not a new allocation. Complete the current original TF evaluator first. New learner plans must be bound by an exact successor READ/protocol; never mutate old family recipes or rewrite existing callbacks. Audit any carried textual experience under the new template-only boundary before admission, preserving the original archive.

Tests run complete synthetic algorithm flows into capsule preparation and adversarially reject expanded knowledge, cases, sample identifiers, extra policy fields, altered request/task/instruction commitments, spent requests and oversized inputs before publication. The original snapshot cannot be overwritten. See validation-v1.json. Runtime/task-quality evidence is still required independently; no claim of optimization benefit is made here.
